
# MINI COURIER PLANNER

## Project Description
Mini Courier Planner is a Python-based application
that helps manage courier parcel delivery.

It prioritizes parcels, selects packages according
to vehicle capacity and generates delivery routes.

## Algorithms Used
1. Merge Sort - Parcel prioritization
2. 0/1 Knapsack - Optimal parcel selection
3. Dijkstra - Shortest path calculation
4. Nearest Neighbor TSP - Delivery route planning

## Technologies Used
- Python
- Matplotlib
- Heapq
- Time module

## How to Run
1. Install Python.
2. Install Matplotlib using:
   pip install matplotlib
3. Open the project folder.
4. Run:
   python main.py

## Output
The application displays:
- Sorted parcels
- Selected parcels
- Shortest paths
- Delivery route
- Performance analysis
